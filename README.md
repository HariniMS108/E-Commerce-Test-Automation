# E-Commerce Test Automation

Automated testing project for an e-commerce application using Python, Selenium, and Pytest.

## Technologies Used

- Python
- Selenium WebDriver
- Pytest
- Pytest-HTML
- API Testing
- Database Testing
- Page Object Model (POM)
